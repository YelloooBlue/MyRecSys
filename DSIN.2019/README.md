# DSIN模型复现（PyTorch）
DSIN（Deep Session Interest Network）是一种基于深度学习的点击率预测模型，旨在捕捉用户在会话中的兴趣演变。本文档介绍了DSIN模型的复现过程，包括数据集准备、数据预处理、构建交互序列数据集以及模型训练等步骤。

> 这篇论文存在一定争议、网上有部分声音认为DSIN相比DIN和DIEN没有明显的创新，且模型复杂度高，在官方论文中也只是在离线数据集上进行了评估，本仓库仅由于学习和复现的目的进行实现，请读者自行评估论文的创新性和实用性。
